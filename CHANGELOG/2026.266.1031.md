# 2026.266.1031 — feat: relocate the feature R10 witness bed from opencharly/charly

## Summary of changes

Relocate the `check-feature-local` R10 witness (and its `check-feature-app` `kind:local` template) out of `opencharly/charly` into the plugin's owning repo, so the bed lives in the repo that owns the artifact it exercises. A check bed must live beside its artifact because the check-bed runner's dev-tree override (`proc.SelfSuperprojectOverridePair`, `spec/proc/repo_override.go`) points the bed PROJECT's own superproject's `@github` refs at the local tree; in this umbrella every submodule's superproject is `opencharly/opencharly` (which hosts no candies), so a plugin candy owned elsewhere was never exercised as in-development code while its witness sat in `charly`. Relocated here, the template composes the LOCAL `plugin-feature` candy with no `@github` pin. The `version:` stamp moves from the old schema to the schema version of the gate binary (`2026.232.0520` → `2026.249.2125`), and the CI pin is bumped past it (`v2026.238.1242` → `v2026.256.1316`, a binary whose schema version is ≥ the stamp) so the pinned `charly box validate` accepts the stamp.

**Changed files:**
- `.github/workflows/deploy.yml` — bumps the pinned charly source `v2026.238.1242` → `v2026.256.1316` (`:25`) so the CI gate's `charly box validate` is newer than the new `2026.249.2125` schema stamp (the old pin predated it and would have rejected it). The CI `build` job on this head passes, confirming acceptance.
- `.gitignore` — a brand-new file (there was no `.gitignore` on `main`; the diff is added `+16/-0`); it contains exactly the 16 standard generated-artifact / editor-scratch / migration-backup rules — `.build/`, `.containerignore`, `.dockerignore`, `.check/`, `output/`, `*.swp`, `*~`, `*.bak`, `*.bak.*`. It is purely additive; no earlier entries existed to preserve.
- `charly.yml` — adds the `check-feature-app` `kind:local` template (composing the LOCAL `plugin-feature` candy) + the `check-feature-local` `disposable: true` bed; migrates the `version:` stamp `2026.232.0520` → `2026.249.2125`; sweeps the now-false "declares no entities of its own" header comment.
